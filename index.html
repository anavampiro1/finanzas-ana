Gastos fijos se reservan solos

Palabra clave: si un pago de Apple Pay la contiene (ej. "sportrade"), se marca como fijo y no se descuenta dos veces. "Hasta": último mes de la cuota (aaaa-mm).

Atajos de iPhone

1 · Apple Pay → se anota solo
  1. App Atajos → Automatización → + → Transacción (Wallet).
  2. Elegí tus tarjetas, todas las categorías y Ejecutar inmediatamente. Siguiente → Nuevo atajo en blanco.
  3. Obtener contenido de URL con la URL de arriba. En la flechita: Método POST, Cuerpo JSON, campos de texto:
    actionapplepaypintu PINmontoEntrada del atajo → ImportecomercioEntrada del atajo → ComerciotarjetaEntrada del atajo → Tarjeta o pase
  4. Mostrar notificación con Contenido de la URL. Pagás y te llega "Hoy te quedan X €" + frase de Pancha.
2 · "Oye Siri, gasto" (efectivo, Bizum…)
  1. Atajo nuevo llamado Gasto: Solicitar entrada (Número) "¿Cuánto?" y otra (Texto) "¿En qué?".
  2. Obtener contenido de URL, POST, JSON: action=rapido, pin, monto=1ª entrada, texto=2ª entrada.
  3. Mostrar notificación con el contenido.
  4. Extra: Ajustes → Accesibilidad → Tocar → Toque atrás → doble toque → "Gasto".
3 · Aviso diario de Pancha
  1. Automatización → + → Hora del día 9:00, Diariamente, Ejecutar inmediatamente.
  2. Obtener contenido de URL (GET):
  3. Mostrar notificación con el contenido. Repetilo 21:30 para acordarte de anotar Bizum/efectivo.
4 · Instalarla como app
  1. Abrila en Safari → Compartir → Añadir a pantalla de inicio. Aparece con el ícono de Pancha.
